# Bento

A local workspace for Markdown notes, projects, and todos, inspired by Obsidian and Notion.

Bento aims to combine portable files with a calm, Notion-inspired interface and a customizable theme system.

## Status

Planning. There is no application implementation yet.

Start with the [product and technical specification](docs/spec.md), which distinguishes requirements from proposed design choices and open questions.

## Initial direction

- Windows and macOS desktop support.
- Markdown files that remain useful outside Bento.
- First-class projects, todos, and free-form tags.
- Integrated document, project, and task views.
- Configurable layouts and installable themes.

## Development

The application framework and build tooling have not been selected. The first milestone is a small cross-platform prototype that validates editing, file safety, and the theme model.
