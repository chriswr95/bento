# Bento preview

A calmer place for projects, meeting notes, and the next steps that follow them.

## Download

- **Mac with Apple silicon:** Bento-macos-arm64.dmg — open it and drag Bento to Applications.
- **Windows Intel/AMD 64-bit:** Bento-windows-x64.zip — Extract All, then open Bento.exe inside the extracted Bento folder.

Choose these files under **Assets**, not Source code. No Node.js, pnpm, account, or terminal is needed. These builds are unsigned; macOS may require approval in Privacy & Security, and managed Windows laptops may require IT approval. Intel Mac and Windows ARM builds are not included in this preview.

Read the [installation guide](https://github.com/chriswr95/bento/blob/main/docs/install.md) for OS prompts, updates, and file locations. SHA-256 checksums are included beside each download.

## Start here

Open Bento and choose **Try an example workspace**. Create/select an empty folder, then follow the short Project → Meeting → Daily review walkthrough. It includes fictional civil-engineering projects and editable notes. Finish with **Create my workspace** when you're ready for your own work.

## In this preview

- Markdown pages, customizable project/todo databases, tags, and related notes.
- Meeting checkboxes become tracked actions; `@` sets dates and properties as you write.
- Daily review across projects, inline completion/rescheduling, and project summaries.
- Themes, a file explorer, quick open, and keyboard shortcuts.
- A refreshed welcome screen and a skippable walkthrough with Back, replay, and an easy handoff to your own workspace.

This is an early trial, not a v1 release. There is no real agent integration, cloud sync, automatic updater, or backup browser. Pre-v1 workspace formats may change. Keep a separate copy of important work.
